## 🇬🇧 English Overview

This directory contains Netlify serverless function adapters (`@expo/server/adapter/netlify`) and routing rules (`netlify.toml`) enabling static Web exports (`expo export -p web`) alongside server-side API routes (`/api/chat`, `/api/pool`, `/api/sandbox`, `/api/models`, `/api/search`, `/api/fetch`) and NVIDIA NIM edge redirects (`/api/nvidia/*`).

## 🇩🇪 Deutsche Übersicht

Dieses Verzeichnis enthält die Netlify-Serverless-Adapter (`@expo/server/adapter/netlify`) und Routing-Konfigurationen (`netlify.toml`), mit denen der statische Web-Export (`expo export -p web`) samt aller Server-API-Routen (`/api/chat`, `/api/pool`, `/api/sandbox`, `/api/models`, `/api/search`, `/api/fetch`) und NVIDIA-NIM-Weiterleitungen betrieben wird.
