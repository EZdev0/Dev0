# 🤖 GitHub Copilot Instructions

When generating code or answering prompts in this codebase, adhere to:

- Master directives in [`AGENTS.md`](../AGENTS.md)
- Coding standards in [`.agent/rules/RULES.md`](../.agent/rules/RULES.md)
- Error logs in [`.agent/rules/LEARNING.md`](../.agent/rules/LEARNING.md)
- User preferences in [`.agent/rules/USER.md`](../.agent/rules/USER.md)

Key Standards:
- Strict TypeScript mode without `any`.
- React Hooks declared before any conditional return statements.
- Direct, concise responses.
