## 🇬🇧 English Overview

`constants/colors.ts` defines the high-contrast dark IDE color tokens (`IDE`) used across all Web, Android, and iOS screens:
- **Surfaces & Borders:** `IDE.bg` (`#090D16`), `IDE.surface` (`#111827`), `IDE.card`, `IDE.border` (`#1E293B`), `IDE.elevated`.
- **Semantic Accents:** `IDE.primary` (`#3B82F6`), `IDE.accent` (`#8B5CF6`), `IDE.green` (`#10B981`), `IDE.yellow` (`#F59E0B`), `IDE.red` (`#EF4444`), `IDE.cyan` (`#06B6D4`).
